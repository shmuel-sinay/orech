# תהליך עבודה יעיל ובטוח יותר — M36 Plus

## מה השתבש עד עכשיו, ולמה
1. עריכה ישירות ב-`/system` → נגמר מקום (40MB על 21MB פנויים).
2. מחיקת קובץ ב-`/vendor/bin/hw/...` **בטעות** במקום `/vendor/etc/permissions/...` → המכשיר לא עלה.
3. ללא גיבוי לפני כל שינוי → כל תקלה דרשה צריבת super מחדש מאפס.

כל שלושת אלה נפתרים ע"י **סדר קבוע**, לא ע"י זהירות כללית.

## הסדר הקבוע מעכשיו, לכל שינוי קובץ ב-/system או /vendor

### שלב 0 — לפני שנוגעים בכלום (פעם אחת, עכשיו)
```
adb shell getprop ro.boot.verifiedbootstate
```
חייב להיות `orange`. אם לא — עוצרים, לא נוגעים בכלום.

### שלב 1 — גיבוי מדויק של המצב הנוכחי (לא סמך על stock ישן)
```
adb pull /vendor/etc/permissions/android.hardware.wifi.xml backup_wifi_perm.xml
adb pull /system/system_ext/priv-app/MtkSettings/MtkSettings.apk backup_settings_CURRENT.apk
adb pull /system/system_ext/priv-app/MtkSystemUI/MtkSystemUI.apk backup_systemui_CURRENT.apk
```
(להריץ את זה **בכל פעם** לפני שינוי חדש — לא "יש לי גיבוי מהשבוע שעבר".)

### שלב 2 — לאשר את הנתיב המדויק לפני מחיקה/עריכה, בלי לנווט ביד
במקום לנווט תיקייה-תיקייה ב-MT Manager (איפה קרתה הטעות), **תעתיק-הדבק את הנתיב המלא** ישירות לשורת הנתיב של MT Manager (יש לו שדה כזה למעלה). זה מבטל סיכוי לבחור תיקייה דומה בטעות.

### שלב 3 — עריכה תמיד ב-/sdcard, לא במקור
(כבר קבענו את זה — ממשיכים ככה.)

### שלב 4 — פריסה (deploy) — רק אחרי שהכל מוכן, לא שלב-שלב עם reboot בין כל קובץ
**לרכז כמה שינויים יחד** (לדוגמה: גם ה-wifi.xml וגם כל עריכת ה-APK שנשארה) **ואז reboot אחד**, במקום reboot נפרד לכל שינוי קטן. זה חוסך זמן וגם מצמצם מספר "ניסויים" על המכשיר.

### שלב 5 — אחרי reboot, צ'ק-ליסט קצר (לא לנחש אם זה עבד)
```
adb shell getprop sys.boot_completed      # אמור להיות 1
adb shell settings get global wifi_on     # אמור להיות ריק/שגיאה
adb shell pm list packages | grep wifi    # לוודא שלא נעלם משהו שלא התכוונו אליו
```

## כלל אצבע אחד שהיה מונע את שתי התקלות
**כל פעולת מחיקה/כתיבה על `/system` או `/vendor` — קודם `adb pull` של אותו קובץ בדיוק
לפני המחיקה, לוודא שזה הקובץ הנכון (שם+גודל), ורק אז למחוק.** זה שלב אחד נוסף,
שלוקח 10 שניות, ותופס גם בעיית "קובץ לא נכון" וגם משמש כגיבוי אוטומטי.
